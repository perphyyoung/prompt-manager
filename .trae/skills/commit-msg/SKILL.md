# 约定式提交消息生成器

## 概述

根据已生成的 diff 文件 (git-diff.log) 生成符合约定式提交（Conventional Commits）规范的中文提交消息建议。**不执行实际的 git commit 操作**，仅输出建议的提交消息供用户参考或手动使用。

## 约定式提交格式

```
<类型>[可选范围]: <描述>

[可选正文]

[可选脚注]
```

## 提交类型

| 类型       | 用途                           |
| ---------- | ------------------------------ |
| `feat`     | 新功能                         |
| `fix`      | Bug 修复                       |
| `skill`    | Skill 相关更改                 |
| `docs`     | 仅文档更改                     |
| `style`    | 格式/样式调整（无逻辑变更）    |
| `refactor` | 代码重构（无功能/修复）        |
| `perf`     | 性能优化                       |
| `e2e`      | 添加/更新 e2e 测试             |
| `test`     | 添加/更新其他测试              |
| `build`    | 构建系统/依赖项                |
| `ci`       | CI/配置更改                    |
| `chore`    | 维护/杂项                      |
| `revert`   | 回滚提交                       |

## 破坏性变更

```
# 在类型/范围后加感叹号
feat!: 移除已弃用的接口

# 或使用 BREAKING CHANGE 脚注
feat: 允许配置继承其他配置

BREAKING CHANGE: `extends` 键的行为已更改
```

## 工作流程

### 1. 分析 Diff

- 如果 git-diff.log 无效(没有该文件, 或文件为空), 提醒用户生成, 结束
- 如果有效, 继续执行

### 2. 生成提交消息

分析 diff 以确定：

- **类型**：这是什么类型的更改？
- **范围**：影响哪个区域/模块？
- **描述**：更改的一行摘要（现在时态、祈使语气、少于 72 个字符）

### 3. 输出建议的提交消息

将生成的中文提交消息以可复制的代码块形式输出，例如：

```
feat(batch-toolbar): 实现图像主界面的批量工具栏

支持 全选/反选/添加标签/收藏/删除/取消 功能
```

**注意：不执行 `git commit` 命令**，由用户自行决定是否使用以及如何使用该提交消息。

## 最佳实践

- 每次提交只包含一个逻辑变更
- 使用现在时态：用 "add" 而非 "added"
- 使用祈使语气：用 "fix bug" 而非 "fixes bug"
- 描述保持在 72 个字符以内

## 安全提示

- 提醒用户检查 diff 中是否包含敏感信息（.env、credentials.json、私钥等）
- 建议用户在执行实际提交前审查生成的消息
