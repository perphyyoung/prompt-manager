# Prompt Manager

本地文生图提示词管理工具，基于 Electron 开发，帮助用户高效管理提示词和关联图像。

## 功能特性

### 标签管理系统

适用于提示词标签和图像标签。

| 功能 | 描述 |
|------|------|
| 标签添加 | 支持为对象添加多个标签 |
| 标签筛选 | 多选标签组合筛选（Ctrl/Cmd 键多选） |
| 标签组管理 | 创建标签组，按优先级排序 |
| 标签拖拽 | 拖拽标签分配到不同组，支持从标签筛选区拖拽到卡片快速添加 |
| 标签排序 | 按使用数量和名称排序 |
| 批量标签管理 | 详情界面支持批量删除标签 |
| 新建/重命名标签 | 支持新建和重命名标签 |

**特殊标签：**

- 提示词：收藏、多图（关联多图）、无图（未关联图像）、安全 / 敏感（评级）、无标（无标签）
- 图像：收藏、未引（未被引用）、多引（被多提示词引用）、安全 / 敏感、无标

### 网格视图与批量操作

**选择方式：** 复选框、Ctrl/Cmd + 点击、Shift + 范围选择、Ctrl+A 全选

**批量操作：** 反选、批量切换收藏、批量添加标签、批量删除（移到回收站）

### 收藏系统

- 卡片上快速收藏/取消收藏
- 通过特殊标签筛选收藏项

### 回收站系统

- **软删除** - 删除的对象移到回收站
- **恢复** - 从回收站恢复对象
- **彻底删除** - 从回收站永久删除

### 完整备份系统

#### 导出功能

- **完整备份** - 导出数据库和所有图像文件为 ZIP 格式
- **不含缩略图** - 缩略图将在导入时从原图重新生成，减小备份体积
- **版本标记** - 包含数据格式版本号，用于兼容性检查

#### 导入功能

- **智能恢复** - 自动解压并恢复数据库和图像文件
- **缩略图再生** - 根据原图自动重新生成缩略图
- **进度显示** - 实时显示导入进度（解压、验证、恢复、生成缩略图）
- **版本检查** - 检查数据格式版本兼容性
- **自动回滚** - 导入失败时自动恢复到原数据
- **完成确认** - 导入完成后需要用户确认，然后重启应用

备份包含数据库、图像文件和 manifest.json 清单；不包含缩略图、字体文件和应用设置。

### 数据管理

- **数据目录** - 查看并打开当前数据存储目录
- **孤儿文件清理** - 导出并删除不在数据库中的图像和缩略图文件
- **重建缩略图** - 扫描所有图像，重新生成丢失的缩略图
- **完整备份** - 数据库与图像打包导出为 ZIP，导入时自动重新生成缩略图，失败自动回滚（详见上文"完整备份系统"）
- **安全模式** - 安全/敏感 内容分级切换
- **清空所有数据** - 一键清空所有数据（保留图像文件）

### 系统功能

| 功能 | 描述 |
|------|------|
| 主题切换 | 明亮/暗黑 |
| 字体设置 | 支持系统字体和自定义字体文件导入 |
| 系统托盘 | 最小化到系统托盘，支持托盘菜单 |
| 禁止二级跳转 | 从提示词详情进入图像详情后，禁止再次跳转 |

### 自动保存系统

- **防抖自动保存** - 输入后 800ms 自动保存
- **字段级变化追踪** - 只保存变化的字段
- **自动调整高度** - textarea 根据内容自动调整高度

### 安全评级系统

- 支持设置 安全/敏感 评级
- **双向联动** - 提示词与关联图像的安全评级双向联动
- 安全模式控制内容显示范围

## 提示词特定功能

### 提示词核心字段

标题、内容、翻译、备注、图像关联

### 图像关联

| 功能 | 描述 |
|------|------|
| 添加图像 | 上传本地图像或从图像库选择 |
| 多图关联 | 一个提示词可关联多张图像 |
| 首图显示 | 卡片视图显示首图背景 |
| Hover 预览 | 悬停显示提示词内容和首图预览 |
| 图像标签显示 | 提示词详情界面显示关联图像的标签 |

### 提示词搜索与排序

- **搜索** - 支持标题、内容、翻译、备注和标签搜索
- **排序** - 按更新时间、创建时间、标题排序

## 图像特定功能

### 图像核心字段

文件名、备注、标签、尺寸（宽 x 高）、文件大小、上传时间

### 提示词关联

| 功能 | 描述 |
|------|------|
| 多引用管理 | 一张图像可关联多个提示词 |
| 解除关联 | 支持解除与提示词的关联 |
| 未引用识别 | 识别未被提示词引用的图像 |
| 提示词预览 | 悬停显示关联提示词内容 |
| 从图像创建提示词 | 从未引用图像直接创建提示词 |

### 图像处理

- **格式支持** - JPG、PNG、GIF、WebP
- **MD5 去重** - 自动检测重复图像
- **缩略图生成** - 自动生成缩略图

### 图像搜索与排序

- **搜索** - 支持文件名、备注和标签搜索
- **排序** - 按更新时间、上传时间、文件名、宽度、高度、文件大小排序

## 技术栈

| 类别 | 技术 | 选型理由 |
|------|------|----------|
| **桌面框架** | Electron 41.2.0 | 前端技术栈开发桌面应用（当前仅支持 Windows） |
| **前端** | 原生 ES2023 | 无需构建步骤，直接运行现代 JS |
| **数据库** | SQLite3 | 轻量级本地存储，无需额外服务 |
| **图像处理** | Sharp 0.35 | 高性能图像处理和缩略图生成 |
| **架构模式** | ES Module + 模块化 | 清晰的依赖管理，支持 Tree Shaking |
| **打包工具** | Vite + electron-builder | 快速构建，生成 Windows 安装包和可执行文件 |
| **代码检查** | OXLint + oxfmt | 高性能 TypeScript/JavaScript 检查与格式化 |

## 快速开始

### 环境要求

- **操作系统**: Windows 10/11（当前仅支持 Windows）
- Node.js ^20.19.0 或 >=22.12.0
- pnpm >= 11.0.0

### 安装与启动

```bash
# 克隆项目
git clone <repository-url>
cd prompt-manager

# 安装依赖
pnpm install

# 启动开发模式
pnpm start
```

### 静默启动（无命令行窗口）

```bash
start-hidden.vbs
```

### 调试模式

```bash
start-debug.bat
```

### 打包构建

```bash
# 构建 Windows NSIS 安装包
pnpm release
```

## 数据存储

默认存储在应用目录下的 `py-data/` 文件夹：

```
py-data/
├── prompt-manager.db      # SQLite 数据库
├── images/{date}/         # 图像文件
└── thumbnails/{date}/     # 缩略图缓存
```

可通过设置界面查看数据存储路径。
