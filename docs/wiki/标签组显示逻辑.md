# 标签组显示逻辑

本文档说明标签筛选区和标签管理界面中标签组的显示规则。

## 首位组识别

首位组由 `TopGroupManager.getTopGroup()` 方法确定：

- 按 `sortOrder` 排序所有标签组
- 返回排序后的第一个组
- **空组(组内无标签)也可以作为首位组**

## 标签筛选区

### 收起时

**文件**: `TagUI.renderCollapsedFilter()`

- 显示特殊标签（收藏、无图、无标等）
- 显示首位组的所有标签（包括计数为0的）
- 显示用户选中的其他标签
- **不显示组标题**

### 展开时

**文件**: `TagUI.renderExpandedFilter()`

显示规则：

| 条件 | 显示行为 |
|------|----------|
| 组无标签 | 不显示该组 |
| 首位组有标签 | 显示组标题 + 所有标签（包括计数为0的） |
| 非首位组有标签 | 只显示计数>0的标签 |
| 未分组标签 | 单独显示在"未分组"区域 |

## 标签管理界面

**文件**: `TagUI.renderTagGroupCards()`

显示规则：

| 条件 | 显示行为 |
|------|----------|
| 未分组标签 | 显示在"未分组"卡片中 |
| 所有标签组 | 按 `sortOrder` 排序显示 |
| 空组 | 显示组卡片，标签区域显示"暂无标签" |
| 首位组 | 显示"首位组"徽章 |

## 对比总结

| 场景 | 首位组识别 | 空组显示 | 计数为0的标签 |
|------|-----------|----------|--------------|
| 筛选区收起 | 基于所有组 | N/A | 首位组显示 |
| 筛选区展开 | 基于所有组 | 不显示 | 首位组显示 |
| 标签管理 | 基于所有组 | 显示卡片 | 始终显示 |
